Tool 3

Development curves

A linear read-out (probe) asks how well the toy's position or identity can be decoded from each model's internal state at each checkpoint. The dashed grey line is the information ceiling: what a supervised network achieves from that age's filtered input. Click legend entries to hide regimes; hover for values. Bands are ±1 s.d. over seeds.

Metrics

  • Position R²: ridge probe of toy position, fitted and tested on adult-quality input.
  • Identity accuracy: probe of toy type (four classes; chance 0.25).
  • Position R² on newborn input: probe fitted on adult-quality input and tested on newborn-quality input (a robustness test).
  • Position R², own-age input: probe fitted and tested on the input quality of the checkpoint's own age. Available when the extended analysis is present in results.json.

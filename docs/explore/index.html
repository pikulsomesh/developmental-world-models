Simulations and tools

Explore the models

Five interactive tools run entirely in your browser. They apply the same developmental filters as the training code, display the stored outputs of the trained models, and chart every result from the repository's result files. Nothing is simulated server-side and no number is typed in by hand.

Tool 1

Infant senses

Drag an age slider from newborn to 12 months and watch one scene pass through the vision, hearing, touch and body-sense developmental filters.

Shows: the exact input each sense model receives at a given age. Data: data/episodes.json. Code: JavaScript port of dwm/senses.py.

Open the tool → Tool 2

Model viewer

Choose a training regime and a checkpoint and see what the vision model was given, what it reconstructs from its latent code and what it predicts one frame ahead. Includes the regime comparison table.

Shows: model outputs for 6 regimes × 4 checkpoints (seed 0). Data: data/models/*.png, data/model_outputs.json.

Open the tool → Tool 3

Development curves

Probe accuracy per checkpoint for every sense and regime, with the information ceiling, own-age probes and newborn-input probes. Series can be toggled; bands are ±1 s.d. over seeds.

Shows: what is linearly decodable as training proceeds. Data: data/results.json.

Open the tool → Tool 4

Hide-and-seek

Play a possible and an impossible occlusion event side by side and read the model's surprise on each, then see which sensory channel drives the fused model's surprise.

Shows: violation-of-expectation index per model and channel. Data: data/model_outputs.json, data/results.json.

Open the tool → Tool 5

Fusion

Compare how well the position of a hidden or visible object can be decoded from vision, hearing and the fused world model across checkpoints.

Shows: occluded tracking and cross-sense fill-in. Data: data/results.json.

Where these tools get their data

All tools read static JSON written by scripts/export_site_data.py from the repository's results/ directory, so they always agree with the paper and wiki. The tools share one script, docs/assets/app.js, which initialises only the tool present on the page. Raw files are listed on Code and data.

How to read the charts

  • R² is the coefficient of determination of a linear read-out; 1 is perfect, 0 is no better than predicting the mean, negative is worse.
  • Mean ± s.d. are over independent training seeds; the number of seeds is shown in each tooltip as n.
  • Checkpoint (months) is a training stage, not a duration of experience (see Scope and limitations).

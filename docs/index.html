Developmental World Models

What does a world model learn from a baby's senses?

Each sense (vision, hearing, touch and body position) gets its own small predictive world model, fed input filtered to match an infant's at each age, and a fusion model combines them. In a small synthetic world, the quality and order of the input change what is learned and how fast.

Code

Code and data

Everything runs on a CPU. Code, results and trained checkpoints are in the GitHub repository.

Run it

git clone https://github.com/pikulsomesh/developmental-world-models
cd developmental-world-models
pip install -r requirements.txt
python -m pytest -q                                    # growth leaves the function unchanged
python scripts/run_experiments.py --quick --out /tmp/q  # short smoke test
scripts/queue.sh                                       # full grid of regimes and seeds

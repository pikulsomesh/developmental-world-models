Models

Architecture, size and checkpoints of every model in the study: four sense world models in six training regimes, and a fusion world model. All source files are linked; the model viewer shows their outputs.

Sense world model family

Every sense uses the same family (source: dwm/models.py, class SenseWorldModel): an encoder e maps what the sense delivers to a latent state, a residual dynamics model f predicts the next latent from the last k latents and the infant's motor command u_t, and a decoder d maps latents back to observations. Latent size D_s is fixed per sense so the fusion interface is stable.

z_t=e_\theta(\tilde o_t),\qquad \hat z_{t+1}=z_t+f_\theta\big([z_t,z_{t-1},\dots,z_{t-k+1}],u_t\big),\qquad \hat o=d_\theta(z)

Vision uses a spatial-broadcast decoder (Watters et al., 2019) so that "where is the object" is easy to express; the other senses use two-hidden-layer MLPs. Vision training additionally weights the loss by motion: per-pixel weights w=1+20\max_c|\tilde o_t-\tilde o_{t-1}| up-weight what moves, a stand-in for infants' orienting to motion.

Objective

\mathcal L=\frac{\sum_t w_t\lVert d(z_t)-\tilde o_t\rVert^2}{\sum_t w_t}+\frac{\sum_t w_{t+1}\lVert d(\hat z_{t+1})-\tilde o_{t+1}\rVert^2}{\sum_t w_{t+1}}+0.1\,\lVert\hat z_{t+1}-\mathrm{sg}(z_{t+1})\rVert^2

Reconstruct the current observation, predict the next one, and keep the predicted latent close to the (stop-gradient) next latent. The loss is evaluated on sub-sequences of 10 frames; \mathrm{sg} is the stop-gradient. Implementation: dwm/train.py (train_sense) and SenseWorldModel.loss.

Growth operator

A growing model widens every hidden layer from n to n' units and lengthens its memory window, without changing the function it computes. New hidden units receive random incoming weights and zero outgoing weights; new (older) memory slots receive zero input weights.

W_1'=\begin{bmatrix}W_1\\ R\end{bmatrix},\quad W_2'=[\,W_2\;\;0\,]\quad\Rightarrow\quad W_2'\,\phi(W_1'x)=W_2\,\phi(W_1x)\ \ \forall x

Function preservation is verified for every layer by a unit test (tests/test_growth.py). The gradient reaching R is multiplied by the zero outgoing weights, so new capacity contributes nothing until those weights move (derived on Theory). The capacity schedule for growing regimes is:

Fusion world model

The fusion world model (FusionWorldModel in dwm/models.py, training in dwm/fusion.py; 92,424 parameters) takes the frozen latents z^s_t of the four grown sense models and a presence mask m^s_t\in\{0,1\}. Each latent is projected to 64 dimensions, a learned modality embedding is added, the masked mean is passed through an MLP, and a windowed dynamics model (window 6) predicts the next fused state.

h_t=\mathrm{MLP}\!\left(\frac{\sum_s m^s_t\,(P_s z^s_t+\epsilon_s)}{\max(1,\sum_s m^s_t)}\right),\qquad \hat h_{t+1}=h_t+g\big([h_t,\dots,h_{t-5}],u_t\big)
\mathcal L_{\text{fus}}=\frac1{|S|}\sum_s\Big(\lVert r_s(h_t)-z^s_t\rVert^2+\lVert r_s(\hat h_{t+1})-z^s_{t+1}\rVert^2\Big)

Read-out heads r_s reconstruct every sense's latent from the fused state, and each sense is dropped independently with probability 0.3 during training so that the fused state learns to carry information about senses that are momentarily missing. Latents are standardised per sense. Fusion is trained once per seed from the grown regime's checkpoints at each age.

Checkpoint list

Every checkpoint is one regime × sense × stage. Checkpoints for seed 0 of the regimes immature input, adult input and immature input + growth are published in the repository under models/ as models/<regime>/seed0/<sense>_<regime>_stage<k>.pt, where the regime identifiers are curriculum_only, adult_scratch and grown and stage index k = 0, 1, 2, 3 stands for 0, 3, 6, 12 months. They are research checkpoints released for reproduction and inspection, not general-purpose or deployable models. The table lists all 96 configurations with their exact parameter counts; the other three regimes are retrained by the scripts listed on Code and data.

Load a checkpoint

Each file stores the width multiplier, memory window and weights. Install the requirements first (see commands).

import torch
from dwm.models import SenseWorldModel

ckpt = torch.load("models/curriculum_only/seed0/vision_curriculum_only_stage3.pt", map_location="cpu")
model = SenseWorldModel("vision", ckpt["width"], ckpt["window"])   # sense: vision, audio, touch, proprio
model.load_state_dict(ckpt["state"])
model.eval()

# o: (batch, time, 3, 32, 32) in [0, 1]; a: (batch, time, 2) motor commands
with torch.no_grad():
    z, zhat = model(o, a)            # latents and one-step-ahead latent predictions
    recon = model.decode_seq(z)      # reconstruction of the input
    pred = model.decode_seq(zhat)    # prediction for the next frame

Inputs must be passed through the matching front end first (dwm.senses.apply(sense, x, age), see dwm/senses.py). Episodes are generated by dwm.env.generate. The snippet follows the save format in scripts/run_experiments.py; it has not been executed against the published files in this site build.

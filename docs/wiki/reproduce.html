Reproduce

Run from the repository root. The models are sized for CPU training; the unit tests are quick.

git clone https://github.com/pikulsomesh/developmental-world-models
cd developmental-world-models
pip install -r requirements.txt
python -m pytest -q                     # unit tests (including function-preserving growth)

scripts/queue.sh                        # train all regimes and seeds (wraps scripts/run_experiments.py)
python scripts/analyze_fusion_voe.py    # fused violation-of-expectation by event and channel
python scripts/analyze_extra.py         # ceilings, own-age probes, statistics, milestones, compute
python scripts/make_paper_figures.py    # figures 1-5 and extended data
report/build.sh                         # build the paper from the template and results
python scripts/export_site_data.py      # regenerate docs/data/*.json for this site

Seeds and conditions are set by the queue scripts (queue.sh, queue_controls.sh, queue_more_seeds.sh). Every number in the paper is written by scripts/fill_report.py from the results files.

To preview this site locally: cd docs && python3 -m http.server 8765 and open http://localhost:8765/.

The site reads these static files; they can be used directly.
